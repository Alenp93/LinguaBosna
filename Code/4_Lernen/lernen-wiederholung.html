So funktioniert der Karteikasten

Jede Vokabel, die du im Vokabeltrainer beantwortest, landet in einer von drei Boxen. Je besser du sie kannst, desto seltener kommt sie dran:

    Eine falsche Antwort schickt die Karte immer zurück in Box 1. Eine Karte steigt höchstens einmal pro Tag eine Box auf.
